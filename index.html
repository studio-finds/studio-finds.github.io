STUDIO FINDS

STUDIO FINDS is a curated editorial project focused on creative workspaces, objects, tools and everyday design.

Studio Finds Publisher

Studio Finds Publisher is a private internal publishing tool used only by the owner of the STUDIO FINDS Pinterest business account. It is not offered as a service to third-party users.

What the application does

The application supports the editorial workflow for STUDIO FINDS and assists with publishing approved organic image Pins.

  • The owner manually selects the product or subject to publish.
  • The owner reviews the final image, Pin title, description, destination URL and destination board before publishing.
  • Pinterest board information is requested from the Pinterest API only when needed to identify the selected destination board.
  • One Pin is created only after the owner explicitly approves that individual publication.

Pinterest API use

Studio Finds Publisher accesses only the authenticated STUDIO FINDS Pinterest account.

It does not access or manage other Pinterest users' accounts, does not collect Pinterest usernames or passwords, does not scrape Pinterest, and does not use Pinterest API data to train or improve artificial intelligence or machine learning models.

Pinterest information obtained through the API is not persistently stored by the application. When Pinterest information is needed, it is requested again from the Pinterest API.

Authentication is performed through Pinterest's supported authorization process.
