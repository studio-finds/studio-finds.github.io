Privacy Policy

Last updated: September 25, 2026

This Privacy Policy describes how Studio Finds Publisher handles information when interacting with the Pinterest API.

Studio Finds Publisher is a private internal publishing tool used only by the owner of the STUDIO FINDS Pinterest business account. It is not available to third-party users.

Pinterest Information Accessed

When required for publishing, Studio Finds Publisher may access information belonging to the authenticated STUDIO FINDS Pinterest account, such as board information and information necessary to create an approved Pin.

The application does not access or manage Pinterest accounts belonging to other users.

Purpose of Access

Pinterest information is accessed only to support the owner's publishing workflow, including identifying the destination board selected by the owner and creating an individually approved Pin.

User Control and Approval

The owner reviews and explicitly approves each individual Pin before it is published.

This review includes the image, Pin title, description, destination URL and destination board.

Studio Finds Publisher does not automatically publish multiple Pins without individual review and approval.

Storage of Pinterest API Information

Information obtained through the Pinterest API is not persistently stored by Studio Finds Publisher.

When Pinterest information is required, the application requests it again from the Pinterest API.

Authentication and Credentials

Pinterest authentication is performed through Pinterest's supported authorization process.

Studio Finds Publisher does not request or collect Pinterest account passwords or session cookies.

API credentials and authorization tokens required to operate the application are treated as confidential credentials and are stored securely for use only by the STUDIO FINDS account owner.

Sharing and Sale of Information

Pinterest API information is not sold, rented or shared with third parties for advertising, data brokerage, audience targeting or unrelated commercial purposes.

Artificial Intelligence and Machine Learning

Information obtained from Pinterest through the Pinterest API is not used to train, fine-tune, improve or develop artificial intelligence or machine learning models.

Scraping

Studio Finds Publisher does not scrape or automatically extract information from Pinterest outside the functionality provided through Pinterest's authorized API.

Third-Party Users

Studio Finds Publisher is not offered to third-party users and does not provide access to Pinterest functionality on behalf of unrelated users.

Changes to This Policy

This Privacy Policy may be updated if the functionality or data-handling practices of Studio Finds Publisher change.
